Abstract

In Phase 2 we moved from exploratory summaries to confirmatory modelling of test-phase correctness, response speed, and response-category behaviour. Three code-level bugs were corrected and nine analyses added. The clearest result is a post-boundary recognition cost in Item + Task Shift, confirmed by Friedman χ²(2)=11.47, p=.003, W=0.117; Holm-corrected dz=−0.477, p=.020; and SDT d' dz=−0.473, p=.016. Response decomposition shows general trace weakening; encoding RT did not predict test correctness; pre-boundary lure FA elevation (dz=+0.381) supports a familiarity-based reinterpretation of the LDI non-replication (observed contrast=−0.031, wrong direction).

Introduction

Dataset: MST data, IIIT Hyderabad SP 2026. Conditions: Item Shift Only (n=56), Item + Task Shift (n=49), Task Shift Only (n=53); 150 test trials each. Positions: post (crossed boundary), mid (within event), pre (before boundary).

Prior work: Zacks & Swallow (2007) and Swallow et al. (2009) showed event boundaries impair memory encoding. Morse et al. (2023) predicted a pre-boundary LDI advantage via hippocampal pattern separation — we re-examine this. Phase 1 found task-rule boundaries slow encoding RT dramatically (Fig. 1), motivating Phase 2.

Methodology
  • QC: RT artifact removal; Shapiro-Wilk (W=0.953, p<.001 → nonparametric warranted)
  • ANOVA + Friedman: Repeated-measures ANOVA & Friedman test on participant-level target accuracy across post/mid/pre per condition
  • Pairwise contrasts: Holm-corrected paired t-tests with Cohen's dz; chi-square on old/new/similar response profiles
  • SDT d-prime: Foil-based FA rate as baseline; d' by boundary position
  • Lure analysis: Spearman (lure bin vs P(similar)); lure FA rate by boundary

H₁: Post-boundary targets show lower recognition than mid/pre when both item and task rule shift simultaneously.

Fig. 1 (Phase 1). Encoding RT by boundary. Task-rule boundaries slow encoding dramatically — F(2,96)=68.36, p<.001 (Item + Task Shift). Motivates Phase 2.
Primary Finding — Phase 2 Confirmatory Result
Post-boundary recognition cost confirmed — Item + Task Shift: Friedman χ²(2)=11.47, p=.003, W=0.117  ·  Post-mid dz=−0.477, Holm p=.020  ·  SDT d': dz=−0.473, p=.016  ·  Not significant in Item Shift Only or Task Shift Only
Results

H₁ confirmed: ANOVA — Item + Task Shift: F(2,96)=6.45, p=.002; Item Shift Only: F(2,110)=0.21, p=.814; Task Shift Only: F(2,104)=4.62, p=.012. Both parametric and nonparametric tests agree only for Item + Task Shift. Per-participant contrast distribution (Fig. 3) shows the effect is consistent across individuals — mean post−mid=−0.073.

Fig. 2. Target recognition accuracy by boundary position. Post-boundary cost is significant only in Item + Task Shift (centre). Points = participant means; diamonds = condition means ± 95% CI.
Fig. 3. Per-participant post−mid target correctness contrast. Item + Task Shift (centre) distribution is shifted left of zero (mean=−0.073) — boundary cost is consistent at the person level.

SDT d-prime & Response Decomposition
SDT (Fig. 4): Post-boundary d' is lowest in Item + Task Shift — Friedman χ²(2)=11.47, p=.003. Post-mid d' contrast: dz=−0.473, Holm p=.016. Null in other conditions.

Response direction: P("old"|target) post-mid: dz=−0.477, Holm p=.028. Both P("similar") and P("new") trend upward but don't survive correction — general trace weakening, not conservative responding alone.
Fig. 4. SDT d' by boundary position. Post-boundary d' dip largest in Item + Task Shift. Error bars ±1 SE.
Lure Analysis & LDI Non-Replication
Lure bins (Fig. 5): P(similar) increases with lure bin across all conditions (Spearman ρ=0.14–0.31, all p<.011) — confirms MST difficulty gradient is intact.

LDI non-replication: Morse et al. (2023) predicted pre-boundary LDI advantage. Observed: x̄=−0.031 (wrong direction). Post-hoc power >54% for dz≥0.30 — null is genuine.

Familiarity account: Pre-boundary lure FA rate is elevated (dz=+0.381, Holm p=.093, marginal) — pre-boundary items encoded with stronger familiarity, making their visual variants feel familiar at test. Reframes LDI null as a familiarity, not pattern-separation, effect.
Fig. 5. P(similar) vs. lure bin by condition and boundary. Increasing trend validates MST structure.
Conclusion & Future Works
  • Post-boundary cost confirmed (H₁): Friedman χ²(2)=11.47, p=.003; post-mid dz=−0.477, p=.020 — Item + Task Shift only. Task-rule shift drives impairment, not item shift alone.
  • SDT d-prime converges: Post-mid d' dz=−0.473, Holm p=.016. Post-boundary d' lowest across all conditions.
  • General trace weakening: "New" misses and "similar" errors both trend upward post-boundary — weakened, poorly differentiated trace.
  • Carry-over null: Encoding RT does not predict trial-level correctness — encoding disruption and memory cost are parallel, not causal.
  • LDI non-replication genuine: x̄=−0.031 (wrong direction); power >54% for dz≥0.30. Pre-boundary lure FA supports familiarity account.
  • MST validity: Lure bin gradient holds (ρ=0.14–0.31); speed-accuracy coupling intact across all boundary positions.

Future work: (1) Test boundary cost in fMRI hippocampal data. (2) Examine Objects-vs-Scenes × boundary with larger samples.
